# AI Automation Starter Kit — v1

A practical, human-reviewed starter kit for freelancers and small businesses. This is original educational content; no third-party service is required.

## How to use
Copy a template, replace bracketed placeholders with non-sensitive details, inspect the output for errors, and approve it yourself before sharing. Never paste customer passwords, financial records, health details, confidential contracts, or other personal data into an unapproved AI service.

## 1. Customer enquiry reply
Prompt: "Draft a clear, friendly response to this fictional or anonymized customer enquiry: [summary]. Our confirmed policy is: [policy]. Offer only these approved next steps: [steps]. Do not promise refunds, dates, or features unless explicitly supplied. Mark missing facts as [NEEDS REVIEW]."

Review: factual accuracy, tone, approved policy, recipient, links. Send manually.

## 2. Meeting action list
Prompt: "From these approved meeting notes: [notes], create a table with action, named owner, explicit due date, and evidence quote. Use 'Unassigned' and 'Not specified' where absent. Do not infer commitments."

Review: owner consent, deadlines, confidential information. Share only after approval.

## 3. Daily priority briefing
Prompt: "Using these non-sensitive sample tasks: [tasks], create a concise daily briefing with at most five priorities. Separate urgent deadlines from optional ideas. Do not invent calendar events or messages."

Review: deadlines against the source; keep private details out of the prompt.

## 4. FAQ draft
Prompt: "Create five FAQs using only these verified facts about our service: [facts]. If a question cannot be answered from the facts, write 'Contact us for confirmation'. Avoid guarantees and invented testimonials."

Review: prices, availability, terms, legal statements.

## 5. Weekly content plan
Prompt: "Plan five helpful educational posts for [audience] about [topic]. Each must solve a concrete problem and include a specific next step. Do not invent statistics, reviews, customer stories, or affiliate relationships."

Review: originality, product accuracy, disclosures, links.

## 6. Human approval checklist
- [ ] All facts and prices independently verified
- [ ] No personal or confidential data shared without authorization
- [ ] No fabricated citations, endorsements, or results
- [ ] Affiliate relationship disclosed wherever relevant
- [ ] A human reviewed the final output before sending or publishing
- [ ] Success metric chosen (minutes saved, error rate, response quality)

## 7. Value measurement worksheet
Track each workflow for two weeks:

| Workflow | Runs/week | Minutes before | Minutes after | Review minutes | Errors found | Notes |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Customer replies | | | | | | |
| Meeting follow-ups | | | | | | |
| Daily briefing | | | | | | |

Net minutes saved per run = minutes before − minutes after − review minutes. If negative, revise or stop using the workflow.

## 8. Seven-day launch plan
Day 1: choose one repetitive, low-risk task.
Day 2: collect sanitized sample inputs.
Day 3: run one template and review the result.
Day 4: document the human approval step.
Day 5: repeat with a second example.
Day 6: compare time and error rate against the manual process.
Day 7: keep, improve, or discard the workflow based on evidence.
