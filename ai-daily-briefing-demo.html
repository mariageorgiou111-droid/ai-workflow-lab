How to build a safe real-world workflow

  1. Choose permitted sources and obtain authorization.
  2. Filter for only necessary fields; redact personal and confidential information.
  3. Summarise with an approved tool, or use manual templates for a free pilot.
  4. Require human approval before sending messages, modifying records or making payments.
  5. Record sources, date, corrections and a deletion schedule.

Agent design: read-only collector → data minimisation → summary draft → human verification → optional approved action. This page performs no external requests.
